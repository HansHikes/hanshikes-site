# Han's Hike Club website

The site at https://www.hanshikes.com. Netlify publishes this repository automatically whenever it changes.

- `index.html` is the whole site. Links and settings are in the `CONFIG` block near the top of the script.
- `logo.png` is the logo. `photos/` holds the site photos.
- Form submissions are emailed to hello@hanshikes.com via Web3Forms.
